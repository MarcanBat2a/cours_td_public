**UE 0 - Algo 3 avec Python** · TD et matériel de séance

Branche : `tp/ue0-04-graphes`

## Récupérer le TD

```bash
git clone https://github.com/MarcanBat2a/cours_td_public.git
cd cours_td_public
git switch tp/ue0-04-graphes
```

Si vous avez déjà le dépôt, `git fetch origin` puis `git switch tp/ue0-04-graphes`.

## Ce que contient la branche

_Le matériel de ce TD sera publié ici avant la séance._

Chaque chapitre a sa branche : `git switch tp/<ue>-<chapitre>`. La branche
`master` en donne la liste.

séance.
